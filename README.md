## FAQ

### What is XCutors?

XCutors is a desktop application package for Windows that bundles several Roblox executor tools and a universal loader for running Lua scripts.

### Is this safe to use?

These tools interact with external applications and may trigger anticomponent alerts. You use them at your own risk and discretion.

### Which Roblox executors are included?

The collection currently includes versions or interfaces for Volt, Synapse Z, Potassium, and Wave, managed by the XCutors Loader.

### How do I update the executors?

The XCutors Loader features an automatic update checker. You can also manually download new versions and place them in the correct folder.

### Does this work on Mac or Linux?

No, XCutors and the included executors are designed specifically for Windows operating systems (Windows 10/11).

### Where can I find scripts to run?

You must source your own Lua scripts from communities and websites that share them. XCutors does not host or provide scripts.

### Why does my anticomponent flag the files?

The nature of these tools (injecting code into another process) is often misidentified as malicious behavior by anticomponent software. You may need to create an exclusion.

### Can I add my own executor to the loader?

The universal loader is primarily designed for the included executors. Adding custom ones may require specific configuration and is not officially supported.
